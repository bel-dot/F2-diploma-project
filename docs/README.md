### Легенда статусів
- `Очікує` — запланований етап (To-do / Backlog).
- `В роботі` — етап у процесі розробки / дослідження (In progress).
- `На перевірку` — етап завершено розробником, очікується рев'ю керівника / консультанта.
- `Готово` — етап верифіковано та закрито (Complete / Done).

## 1. Дослідження предметної області, аналіз аналогів та формування вимог до програмної системи.

[Сформований Google Docs документ](https://docs.google.com/document/d/1-l66hRcgK97J8OOeQDIjUpNBU9nuMblgmZmcQnLhWKA/edit?usp=sharing)

### Коротка витримка нефункціональних вимог (Non-functional Requirements)

1. Час генерації сегмента <= 8.0 ms (p99 <= 12.0 ms)
2. Час інтеграції згенерованого пакету даних в потік рушія <= 1.2 ms
3. Обсяг динамічних алокацій у керованій купі = 0 байт/кадр
4. Пропускна здатність верифікації >= 500 сегментів/с
5. TelemetrySnapshot struct = Client RAM only
6. Конфігураційні файли в JSON Schema.
7. Вікно похибки реаккції користувача >= 150 ms
8. ReachabilityGraph має бути ідентичним в незалежності від характеристик машини користувача.
9. Перевищення ліміту часу генерації в 15 ms перериває операцію та підставляє шаблон з локального кешу.
10. Математичне ядро є незалежною бібліотекою класів на платформі .NET 8.0.
