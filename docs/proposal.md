### Проєктна пропозиція кваліфікаційної роботи бакалавра

**Тема:** Метод та програмні засоби адаптивної процедурної генерації рівнів на основі кінематичного аналізу траєкторій у двовимірному просторі

**Topic:** Method and software tools for adaptive procedural level generation based on kinematic trajectory analysis in two-dimensional space

**Напрям / Спеціальність:** F2 — Інженерія програмного забезпечення

#### 1. Актуальність та проблематика

Створення фізично-залежних двовимірних платформерів із високою динамікою пересування гравця традиційно вимагає значних часових витрат на ручний левел-дизайн та контроль якості прохідності простору. Існуючі алгоритми процедурної генерації (PCG) переважно фокусуються на структурно-плитковій (tile-based) топології, ігноруючи динамічні кінематичні характеристики агента (інерція, збереження моменту імпульсу, прискорення).

Критичною інженерною проблемою є відсутність гарантії топологічної та кінематичної досяжності кінцевих точок рівня без проведення ручного тестування. Метою роботи є розробка архітектури програмного комплексу, що поєднує метод параметричної генерації простору із вбудованою підсистемою формальної верифікації прохідності на основі аналізу досяжних станів (reachability analysis) та динамічного підлаштування складності під метрики взаємодії користувача.

#### 2. Об'єкт і предмет дослідження

* **Об’єкт дослідження:** процес процедурної генерації ігрового простору та динамічної валідації навігаційних обмежень.
* **Предмет дослідження:** методи кінематичного моделювання траєкторій, алгоритми пошуку шляху у фазовому просторі станів та архітектурні патерни проектування автономних систем процедурної генерації.

#### 3. Функціональні вимоги та програмні підсистеми

* **Кінематичне ядро агента (Kinematic Controller Module):** програмна модель розрахунку просторово-часових обмежень руху (вектори сил, фази стрибка, збереження швидкості, тертя поверхні).
* **Модуль адаптивної процедурної генерації (Adaptive PCG Engine):** генератор геометрії та перешкод, що адаптує просторову складність і частоту точок опори на основі поточної оцінки навичок гравця (Dynamic Difficulty Adjustment).
* **Підсистема автоматизованої верифікації прохідності (Automated Headless Validator):** агент на базі алгоритму пошуку у фазовому просторі станів (модифікований $A^*$ / Kinodynamic RRT) для побудови графа досяжності та стрес-тестування згенерованих топологій без використання графічного конвеєра.
* **Модуль збору телеметрії та серіалізації:** механізм експорту топології рівнів та профілів пересування у форматі JSON/Protobuf для регресійного аналізу помилок генерації.

#### 4. Технологічний стек та інструментарій

* **Мови розробки:** C# (.NET 8/9 — обчислювальне ядро алгоритму, серіалізація, логіка валідації); GDScript (інтеграція з вузлами рушія).
* **Середовище та компоненти:** Godot Engine v4+ (фізичний симулятор та візуалізація), NUnit (модульне та регресійне тестування розрахункових алгоритмів).
* **Інженерна інфраструктура:**
* Git (контроль версій із дотриманням GitFlow);
* CI/CD (GitHub Actions) для автоматизованого збирання проєкту, прогону юніт-тестів та генерації звітів валідації рівнів у headless-режимі.
